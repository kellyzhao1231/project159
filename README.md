# FlowNP: Flow Matching Neural Processes

A clean re-implementation and benchmark of **Flow Matching Neural Processes** ([Wildberger et al., NeurIPS 2025](https://arxiv.org/abs/2409.19054)), developed as part of Stanford's Probabilistic Learning research in [Vasanawala Lab](https://med.stanford.edu/vasanawalalab.html).

FlowNP combines **Neural Processes** (meta-learning for predictive distributions over functions) with **Conditional Flow Matching** (learning velocity fields instead of Gaussian outputs), enabling flexible probabilistic predictions on irregular, variable-length spatial data.

## Method

### Training (Conditional Flow Matching)

The model learns a velocity field $v_\theta$ by regressing onto the linear interpolation path between noise and ground truth:

$$\mathcal{L} = \mathbb{E}\_{t,\, y_0,\, y_1}\left[\lVert v_\theta(y_t,\, t \mid \mathcal{C},\, x_t) - (y_1 - y_0) \rVert^2\right]$$

where $y_t = t \cdot y_1 + (1-t) \cdot y_0$, with $y_0 \sim \mathcal{N}(0, I)$ and $t \sim \mathcal{U}(0,1)$.

### Inference (Stochastic Euler Integration)

At test time, predictions are generated by integrating the learned velocity field from Gaussian noise:

$$y_{t+\Delta t} = y_t + \bigl(\alpha(t) \cdot v_\theta + \sigma(t) \cdot \epsilon\bigr) \cdot \Delta t$$

with time-dependent coefficients $\alpha(t) = 1 + t(1-t)$ and $\sigma(t) = 0.2\sqrt{t(1-t)}$.

## Architecture

```
Input Tokens
  Context: [FourierEncode(x_c || t=1) || y_c]
  Target:  [FourierEncode(x_t || t)   || y_t]
         |
    Embedding MLP (4 layers)
         |
    Transformer Encoder (6 layers, 4 heads)
         |
    Velocity Head (2-layer MLP)
         |
    v_theta (predicted velocity)
```

**Key design choices:**
- Fourier positional encoding of spatial coordinates + flow-time
- Full bidirectional attention over context and target tokens
- Proper padding masks for variable-length sequences
- ~0.23M parameters (lightweight and fast to train)

## Datasets

| Dataset | Type | x_dim | y_dim | Description |
|---------|------|-------|-------|-------------|
| **PeakWeather** | Spatial | 2 | 4 | Swiss weather stations (temperature, pressure, humidity, wind speed) |
| **GDP** | Spatial | 3 | 3 | Ocean drifter trajectories (velocity, sea-surface temperature) |
| **GP-RBF** | Synthetic | 1 | 1 | Gaussian process with RBF kernel |
| **GP-Matern** | Synthetic | 1 | 1 | Gaussian process with Matern-5/2 kernel |
| **GP-Periodic** | Synthetic | 1 | 1 | Gaussian process with periodic kernel |
| **MNIST** | Image | 2 | 1 | 28x28 grayscale image inpainting |
| **CelebA** | Image | 2 | 3 | 32x32 face image inpainting |

## Results

### MNIST Image Inpainting (50 epochs, 0.23M params)

| Metric | Value |
|--------|-------|
| Final Train Loss (CFM) | 0.0386 |
| Final Test Loss (CFM) | 0.0458 |
| Prediction MSE | 0.167 |

Training converges smoothly with no overfitting, with test loss improving at every evaluation checkpoint.

## Getting Started

### Requirements

```
torch
numpy
pyyaml
torchvision  # for MNIST/CelebA experiments
matplotlib   # for visualization
```

### Training

```bash
# Spatial datasets
python flownp_spl/train.py --config flownp_spl/configs/weather.yaml --device cuda:0
python flownp_spl/train.py --config flownp_spl/configs/gdp.yaml --device cuda:0

# Synthetic Gaussian process
python flownp_spl/train.py --config flownp_spl/configs/gp_rbf.yaml --device cpu
python flownp_spl/train.py --config flownp_spl/configs/gp_matern.yaml --device cpu
python flownp_spl/train.py --config flownp_spl/configs/gp_periodic.yaml --device cpu

# Image inpainting
python flownp_spl/train.py --config flownp_spl/configs/mnist.yaml --device cpu
python flownp_spl/train.py --config flownp_spl/configs/celeba.yaml --device cuda:0
```

Checkpoints are saved to `flownp_spl/checkpoints/<dataset_name>/`.

### Notebooks

- **`notebooks/flownp_tutorial.ipynb`** -- In-depth mathematical tutorial covering the FlowNP algorithm, architecture, and training procedure
- **`notebooks/experiment_guide.ipynb`** -- Practical walkthrough of the full training pipeline with live demos
- **`notebooks/eval_weather.ipynb`** / **`eval_gdp.ipynb`** -- Evaluation notebooks for spatial datasets
